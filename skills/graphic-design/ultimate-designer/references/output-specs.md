# Output brief template

Fill this in for each job; leave unknowns explicitly pending, not guessed.

| Field | Value |
|---|---|
| Deliverable and intended use | Pending |
| Approved company guide / version | Pending |
| Source content / product-data version | Pending |
| Quantity, pages, and variants | Pending |
| Trim size or digital pixel dimensions | Pending |
| Bleed and content-safe area (if print) | Pending vendor specification |
| Fonts and logo source / rights | Pending |
| Required color space, PDF standard, profiles (if print) | Pending vendor specification |
| Required image resolution at placed size (if print) | Pending vendor specification |
| Sticker cut/white-ink layers (if applicable) | Pending vendor specification |
| Editable source and export formats | Pending |
| Approval owner and checkpoint | Pending |

Decide these before calling any layout "final." Use the actual printer's rules instead of treating sample values in other design skills as universal. A visual mockup is not a production file.
