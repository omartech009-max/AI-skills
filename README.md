# AI-skills
This repository is going to contain all the needed skills for my workflows and projects. It will have many. Some will go to the graphic design skills, others will go to the copywriting skills, and some will be in the token reduction skills. We'll keep adding skills here until we have a full set of useful, categorized skills that our agents can use.

## Graphic design

- [`ultimate-designer`](skills/graphic-design/ultimate-designer/SKILL.md): adapted still-visual design skill for brand-consistent catalogs, flyers, posters, stickers, product imagery, and complex components. It includes art-direction guidance, data/layout integrity gates, and an output brief. It does **not** build websites or video.

The skill is documentation for a future designer-agent workflow, not an installed agent or a working production pipeline. The company guide, tool connections, and printer specifications must be supplied and verified before production.
